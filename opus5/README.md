# U.S.S. Enterprise NCC-1701-D

用 Three.js 从零程序化生成的**银河级企业号**：外部是按官方主尺度建的完整舰体，内部是可以用第一人称走进去的六处舱室。

**没有任何外部模型或贴图文件** —— 所有几何、蒙皮、法线贴图、LCARS 面板、星云与行星都是运行时算出来的。

```bash
npm install
npm start          # 启动后会打印本机与局域网地址
npm test           # 几何回归测试
```

`npm start` 默认监听 `0.0.0.0:8123`，同一局域网的其他设备可以直接用打印出来的 `http://<本机IP>:8123` 打开。
换端口用 `PORT=9000 npm start`，只想本机访问用 `HOST=127.0.0.1 npm start`。

> 触屏设备目前只能用外部视角（可单指旋转、双指缩放）；舰内第一人称依赖指针锁定与键盘，手机/平板上无法行走。

## 规模

| | 本模型 | 官方设定 |
|---|---|---|
| 全长 | 647 m | 642.5 m |
| 全宽 | 460 m | 463.7 m |
| 全高 | 165 m | 195.3 m |

1 world unit = 1 米。舰内一切按人体尺度建模（眼高 1.64 m，走廊净宽 2.64 m，甲板层高 3 m）。

## 外部

- **碟部**：18 点纵剖面绕椭圆平面旋成的单一连续曲面（顶面/边缘/底面一次成形，无接缝），带首尖尾收的平面修形
- **次船体**：12 段控制剖面放样，超椭圆截面带肩部与龙骨
- **颈部 / 挂架**：NACA 翼型截面沿后掠路径放样
- **引擎舱**：10 段剖面 + 巴萨德收集器（旋涡等离子 shader）+ 曲速线圈栅格（流动脉冲 shader）
- **细节层**：约 1900 扇舷窗（逐窗随机亮度，含熄灯窗）、救生艇舱门阵列、RCS 四联推进器、相位炮列、航行灯频闪、主偏导盘、冲量引擎、机库舱门与力场、以及沿曲面法线散布的数千个 instanced greeble
- **蒙皮**：三层嵌套装甲板的 aztec 贴图（2048²），由高度图 Sobel 卷积生成法线贴图，粗糙度独立通道
- **涂装**：舰名与舷号按碟部高度场蒙皮贴合（平面投影会穿模）

## 架构

```
src/
├── core/        渲染器、后期、星空环境、外部轨道相机、第一人称控制
├── lib/         参数曲面、放样、纵剖面、greeble 散布与 instancing
├── materials/   程序化贴图生成、材质库、自定义 shader
├── ship/        碟部 / 次船体 / 颈部挂架 / 引擎舱
├── interior/    舱室构件库 + 六处舱室 + 锚点表
├── systems/     行走与碰撞
└── ui/          LCARS HUD
```

### 几个关键实现约束

- **舱内与舰外分图层**：舰内构件全在 layer 1，恒星平行光只作用于 layer 0。否则没有阴影的情况下，阳光会直接"穿过"船壳照亮舱内墙面。
- **舱室锚点必须落在外壳内侧**：舰桥地板要高于碟部顶面，机库要避开尾部收窄段，否则舱内会看到被阳光照亮的船体外皮。`interior/index.js` 的 `ANCHORS` 注释了这些约束。
- **bloom 之前必须做 HDR 卫生**：任何一个 NaN 像素经过可分离高斯模糊会扩散成整块矩形黑斑。`postfx.js` 的 sanitize pass 负责清零，同时所有 shader 的 `pow()` 底数都做了非负夹紧（GLSL 的 `pow` 对负底数返回 NaN）。
- **参数曲面法线方向**：`cross(dU, dV)` 的朝向取决于参数方向，写错就会整体"反着打光"。`npm test` 用断言守住这一点。

## 测试

`npm test` 校验：所有外壳曲面法线朝外、顶点属性无 NaN/Inf、无零长法线、主尺度落在官方设定的公差内。
